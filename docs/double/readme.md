# Double-Submissions

[rockforms=Quickstart]

RockForms will prevent your forms from being submitted multiple times. This can happen on badly programmed forms when the user reloads the page after submitting the form.

- Submit the demo form above
- Then reload the page

RockForms will automatically detect that and redirect you back to an empty form!

<div class="uk-alert">Note: RockForms will add "?form-success=Quickstart" to the page url on success. You can customise that parameter in the module settings and you can use it with your analytics-software to track form submissions.</div>
